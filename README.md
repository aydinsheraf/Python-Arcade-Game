# Cyberpunk AI Space Shooter 🚀

An interactive arcade game built with Python, OpenCV, and MediaPipe. Uses real-time hand-gesture controls and AR face tracking.

## Features
- **Hand-Gesture Controls:** Track your index finger to move and lift your middle finger to shoot.
- **AR Facial Overlay:** Dynamically tracking cyber-sunglasses using facial mesh landmarks.
- **Arcade Effects:** Custom procedural laser sound synthesis, particle explosions, power-ups, and hit combos.
- **Leaderboard System:** Local high-score tracking with snapshot pilot registration.
